# Data directory

This release stores only **paper-reported aggregate values** in paper_reported/. The CSVs transcribe the supplied manuscript's tables and support plotting descriptive summaries.

The exact 55-bus benchmark inputs and raw per-sample measurements/states are not included. No synthetic replacement data is passed off as the paper's dataset. Before adding the original benchmark, verify its source, licence, redistribution terms, measurement configuration, and reference convention; document file hashes and provenance.
