# Evaluation protocol

The paper reports voltage-magnitude and angle error, physical-consistency metrics (measurement residual, active/reactive mismatch, constraint-violation rate), relative OOD degradation, numerical observability diagnostics, topology-distance regression, paired bootstrap intervals, Wilcoxon signed-rank tests, and effect sizes.

The evaluation implementation was not included in the supplied source files. See [benchmark protocol](../docs/benchmark_protocol.md), [results](../docs/results.md), and [reproducibility status](../docs/reproducibility.md).
